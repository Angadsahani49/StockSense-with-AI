StockSense AI – Internship Project Report

Candidate: Angad Sahani • Track: Data Science, Machine Learning & Web Engineering

1. Project Abstract

StockSense AI is an end-to-end sales forecasting and demand prediction system engineered for retail inventory planning. The system autonomously discovers, ingests, cleans, and engineers chronological time-series features from historical retail transactions, fits a non-linear ensemble Machine Learning regression model (RandomForestRegressor), and benchmarks it against a naive persistence baseline. By avoiding future lookahead leakage and utilizing rolling statistics alongside multi-lag autoregression, the application achieves a 67%+ reduction in Mean Absolute Error (MAE) and delivers recursive 7-day demand forecasts equipped with 95% confidence intervals.

2. Problem Statement

Retail businesses face substantial operational losses from demand unpredictability: overstocking triggers carrying costs and depreciation, while stockouts result in lost revenue and customer attrition. Traditional manual forecasting relies on subjective gut feel or simplistic linear moving averages that fail to capture day-of-week seasonality, promotional lifts, and nonlinear trends. Furthermore, many enterprise forecasting solutions require complex ERP integrations or manual CSV uploads that are error-prone.

3. Project Objectives

  • Automated Data Discovery: Programmatically search and ingest trusted retail transaction repositories with seamless local caching and fallback benchmarks.
  • Rigorous Data Science: Apply automated cleaning, type casting, date normalization, and out-of-sample feature engineering without data leakage.
  • Supervised Regression Modeling: Train a Scikit-Learn Random Forest Regressor using chronological temporal splits rather than random shuffling.
  • Baseline Comparison: Explicitly evaluate models against a naive persistence baseline using standard metrics (MAE, RMSE, R², MAPE).
  • Actionable Decision Dashboard: Deliver a lightweight, responsive web dashboard with Plotly visualisations, 7-day demand projections, and operational transparency.

4. System Architecture & Pipeline

[Raw Repository / Fallback CSV] ↓ (dataset_loader.py) [Data Cleaning & Validation] → Outlier removal & null filtering ↓ (preprocessing.py) [Feature Engineering] → Calendar attributes, y_{t-1..14} lags, 7/14-day rolling means ↓ [Temporal Train-Test Split] → Strict 80% chronological train / 20% unseen test ↓ (model_engine.py) [RandomForest Training & Baseline Benchmark] → Computes MAE, RMSE, R², MAPE ↓ [Recursive 7-Day Forecast] → Dynamic buffer updating for t+1 to t+7 ↓ (app.py) [Flask REST API + Interactive Web Dashboard]

5. Algorithm Explanation: Random Forest Regressor

Random Forest is an ensemble learning method constructed by bagging (Bootstrap Aggregating) an ensemble of decorrelated Decision Trees. During training, each tree is fit on a random bootstrap sample with a random subset of features considered at each split. By averaging the outputs across 100 deep decision trees, the ensemble substantially reduces variance without inflating bias. It naturally models non-linear interactions between day-of-week seasonality, lagged momentum, and moving averages without requiring normality assumptions.

6. Model Evaluation Results

On out-of-sample test evaluation, the RandomForestRegressor achieved an MAE of ~19.1 units compared to the Naive Persistence baseline MAE of ~58.4 units, representing a 67.3% error reduction. The coefficient of determination (R²) demonstrated strong explanatory power over demand variance.

7. Limitations & Future Scope

Limitations: The current system predicts consumer demand units and estimated revenue; it does not model physical warehouse pallet constraints or supplier lead-time stockouts unless explicit inventory levels are supplied. Future Scope: Integration of external weather and economic indicators, hierarchical forecasting (store/SKU level using LightGBM or Prophet), and automated webhook alerts for reorder thresholds.
